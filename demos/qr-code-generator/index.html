Text is encoded locally. It is not sent to a QR service. Scan-test the downloaded code before sharing it. Browser edition supports text, colours, error correction and PNG export; logo and frame tools remain in the desktop version.

Interactive browser adaptation of the Python desktop project. Uses the MIT-licensed QR encoder by Kazuhiko Arase.
