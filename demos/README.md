# Project demos

These static release copies are hosted by the portfolio's existing GitHub Pages deployment. Original repositories remain the source of truth. `sources.json` records the source directory and commit for each published copy.

To release an update, copy the listed source directory's HTML/CSS/JavaScript into its matching demo directory, run the relevant checks, then update the source commit in `sources.json`. Portfolio Generator and Age Calculator are native web projects; Weather Dashboard is a repaired web app; the other demos are labelled browser adaptations of desktop projects.

Do not copy desktop password stores, API-key config files, student data, score files or generated build caches into this directory.
